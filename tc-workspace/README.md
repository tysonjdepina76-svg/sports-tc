# TC Workspace

This folder consolidates the NBA/WNBA TC files from the current build stream.

## Main app
- `apps/sports-tc/` — unified NBA/WNBA TC workflow pipeline and dashboard source.

## Key folders
- `core/` — reserved for canonical engine files.
- `apps/` — app/dashboard code.
- `rosters/` — WNBA/NBA roster builders and roster exports.
- `reports/` — markdown/PDF/text reports and projection printouts.
- `backtests/` — reserved for backtest suites/results.
- `data/` — JSON/CSV outputs.
- `scripts/` — standalone Python TC scripts.
- `archives/` — older snapshots and supporting folders.
- `docs/` — documentation and notes.

See `INVENTORY.md` for the file list.
